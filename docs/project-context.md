# 项目跨版本契约

这里只保存换版本后仍必须成立的工程和状态边界。任务路由见根目录 `AGENTS.md`；当前状态见 `AGENT_HANDOVER.md`；历史见 `progress.md`；玩家中文见 `CopyWriting_Guideline.md`。

## 事实与生成

- 当前实现事实以现场 Git、版本常量、生成数据和实际测试为准。
- 玩家内容只改 `content/zh-CN/` 与生成器中确属玩家可见的作者源；`data.json` 只由 `tools/generate-v5-data.mjs` 写出。
- 同一发布中的 `index.html`、`game.js`、生成器、`data.json`、README 和测试版本断言必须一致。
- 生成器连续运行两次，第二次不得产生差异。Schema 或活动存档迁移必须单独批准。

## 状态所有权

| 事实 | 唯一来源与合法写入 | 其他系统的边界 |
|---|---|---|
| 学历、申请、报到、教育地区与教育证据 | `education`；教育 transition／申请结算 | 就业只读取；只能同步实际取得的 `entryCredential` |
| 岗位、合同、就业状态、职业层级与职业收入 | `employment`；就业 transition／招聘结算 | 家庭、住房、债务和晚年不创建平行职业事实 |
| 父母、伴侣、子女与家庭关系 | `people` 与 `relationships`；人物与关系命令 | `childCount` 等派生值不能创建人物；social 不另存家庭人物 |
| 持续社会人物 | `people[*].social` 与 `social` 两个终身槽位 | `relationships.network` 是认识面，不等于具体朋友或办事能力 |
| 当前主要住处 | `housing`；只通过 `transitionHousing`／`socialCoResidence` | `finance.housingDisposition` 只保存不可逆处置历史 |
| 逐笔债务 | `finance.liabilities`；债务专用命令 | 第二笔债务不重启同名 episode，也不清空第一次危机历史 |
| 习惯类型、阶段、风险与恢复年限 | `habits`；习惯事件结算 | 健康和压力只接收明确效果，不凭文案推导诊断或康复 |
| 卡牌介入 | 当前选择的 `cardInteraction` 与合法 patch | 不突破年龄、学历、执业、人物、住房所有权或债务硬门槛 |
| Episode 与延迟回响 | `episodes`、`scheduledConsequences` 与对应 memory key | 刷新、恢复和迁移不得重复结算；失效按既有语义收束 |
| 存档与版本恢复 | 当前 Schema 默认值、normalize／merge 与迁移入口 | 不通过 UI 标签或玩家文案回写事实 |

## 事件与人物不变量

- Episode 每阶段最多一次关键选择；结果单独确认但不重复结算。短期簇最长五年，到期必须明确收尾；同时最多两个活动簇，同 lane 不并行；人物、单位和资格在启动时绑定。
- 卡牌 `explanation` 与 `resultSuffix` 可以省略；卡名足以说明介入时不复述选项，只有新增可观察事实时才保留后缀。
- 关系结束、搬远或转为伴侣不释放 social 的两个终身人物槽。`relationships.network`、办事能力、海外联系、主动独处和孤独保持不同语义。
- referral 只创建就业入口；朋友合住仍走住房事务；危机支持不能清债、治病、结束照护或凭空生成永久住房。
- `housing` 是当前主要住处的唯一事实源。临时落脚不清产权与按揭；债务解除不恢复已经处置的住房。
- `later.retirement` 只表示工作转段，不自动证明养老金资格或完整晚年身份。
- 只有声明 `recurrence` 的普通 beat 可以复发：同句至少间隔八年，同组至少间隔三年，并读取时间线历史；选择、后果、事件簇和不可逆事实继续一次性。
- 普通住房选择最多三次且类型不重复；只有债务使当前住房无法维持时，允许一次 `debtRelief` 第四次。自动宿舍、按揭结清和事实清理不占次数；成交后的住房价值不随年度自动变化。
- 社交不确定结果最多使用三个显式、稳定的创作变体，刷新和恢复不重抽。延迟回响绑定原人物；人物死亡、关系结束或槽位失配后按既有规则失效。

## 研究与现实

- 制度、法律和医学规则以高可靠资料校正；媒体用于常见矛盾，论坛和社交媒体只提供生活细节。
- 不复制可识别私人经历，不把离奇个案写成普遍规律，也不把当前政策永久写死在远期年代。
- 普通饮酒、游戏、购物、用药、远程工作或关系摩擦不能自动判为危机。
- 两种以上合理产品行为、现实制度与既定游戏规则冲突，或文案无法诚实表达游戏化简化时，停止并交回用户。

## 验证契约

- 根目录 `smoke.js` 是统一入口：无参数为核心检查，`--fast` 为语法检查，`--full` 为发布档；底层 profile 由 `tests/run-checks.cjs` 维护。
- `--changed` 只自动处理证据明确的路径；`game.js`、生成器等多领域文件需要显式声明 scope。
- 新不变量优先进入现有 regression；不按版本号创建纪念性 smoke，也不把大量代表人生固化成 mega smoke。
- 正常改动先跑一个相关静态检查和一条代表真实路径。共享基础设施、高风险跨域改动或发布前才扩大到 `full`。
- 涉及卡片或抽屉时检查 320×568、360×640、360×773，控制台错误为 0。
- 自动测试证明合同和路径，不替代文案质感、概率体感和整局节奏的人工判断。默认不运行批量人生模拟。

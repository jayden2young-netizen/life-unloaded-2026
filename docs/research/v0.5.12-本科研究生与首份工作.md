# v0.5.12 本科、研究生与首份工作研究档案

更新时间：2026-07-26

## 研究目标与方法

本档案服务于《人生尚未加载 · 2026》v0.5.12 的短期事件簇。范围从本科正式报到开始，到课程、社团、休学／转专业／转学、读研准备与就读，再到第一份工作的录用或持续求职；不重复 v0.5.10 已完成的国内外本科申请。

资料分级：

- A 级：教育、人社、移民和欧盟／国际组织官方材料，用于流程、资格和政策边界。
- B 级：同行评审研究、调查和可靠媒体，用于常见困难、差异与社会背景。
- C 级：公开自述和社区讨论，只用于合租厨房、群聊、社团、面试等生活物件和语气；不用于概率、金额或普遍结论。

角色的未来可能落在 2040 年代以后。因此只编码“需要核对工作资格、学校细则、学分、资助和材料”等稳定机制，不写死 2026 的具体许可期限、工资门槛或单一国家政策。

## 可编码事实

### 中国国内本科

- 教育部《普通高等学校学生管理规定》要求学校真实记录成绩；转专业由学校制定标准和程序，转学通常需要本人申请、转出与转入学校审核，休学和复学要在学校规定的最长学习年限内完成。[教育部学生管理规定](https://www.moe.gov.cn/srcsite/A02/s5911/moe_621/201702/t20170216_296385.html)
- “能申请”不等于“能转成”。培养方案、先修课、成绩、名额、学期窗口、两校同意和材料公示可以变成真实的游戏门槛。
- 社团、竞赛、实验室、学生工作、实习和课程项目提供的是不同类型的成长证据。它们会争夺时间，但不应存在一条对所有专业都正确的履历模板。
- 休学不是自动失败。办妥手续、保留成绩和复学窗口，与直接失联、长期欠费或超过学籍期限应当是不同结果。

### 国内研究生申请与就读

- 2026 全国硕士研究生招生仍分为报名、初试、复试、调剂与录取；招生单位公开细则，调剂通过统一系统进行，最终结果不是单次“考上／没考上”。[2026 招生工作管理规定](https://yz.chsi.com.cn/kyzx/jybzc/202509/20250925/2293432170.html)、[2026 调剂注意事项](https://yz.chsi.com.cn/kyzx/tjzd/202604/20260407/2293459531.html)
- 海外本科回国申请还可能需要学历学位认证材料。游戏应把“成绩和研究经历不错”与“材料已可提交”分开记录。
- 读研可增加研究、专业和行业证据，也会付出时间、资助、导师关系和机会成本；学历本身不承诺对口岗位或更高起薪。

### 美国与欧洲学习

- 美国学生工作与实践训练受在读身份、学校授权、专业关联和雇佣记录等条件约束；游戏只保留“先核工作资格和学校授权”的机制。[USCIS 学生就业](https://www.uscis.gov/node/92822)、[USCIS 实践训练](https://www.uscis.gov/node/92821)
- 欧洲高等教育常以学分累计和互认为骨架，但实际课程、补考、毕业和转校细则仍由项目和学校执行。[欧盟 ECTS](https://education.ec.europa.eu/education-levels/higher-education/inclusive-and-connected-higher-education/european-credit-transfer-and-accumulation-system)
- 国际学生毕业后通常仍需经过限时求职许可、雇主匹配或身份转换，能留下不等于能长期留下；语言、当地经验、职业准入和雇主对手续的接受度会影响第一份工作。[OECD 2026 国际学生报告](https://www.oecd.org/en/publications/international-students-in-higher-education_005ff28d-en/full-report/post-graduation-opportunities-and-possibilities_42892cac.html)

### 华人在外的生活与社会融入

- 对荷兰中国学生的访谈显示，跨文化友谊会受到语言理解、文化距离、活动兴趣、双方主动性和感知偏见影响。[荷兰访谈研究](https://www.dare.uva.nl/id/e260935f-0c76-4819-ad08-b65d9398bd11)
- 芬兰研究显示，同胞和跨国网络也能促进有意义的跨文化接触；因此“中国朋友多”不能作为融入失败或能力惩罚。[芬兰研究](https://journal-njmr.org/articles/10.1515/njmr-2018-0008)
- 欧洲六国调查把语言限制和文化差异与学习、日常任务、社交整合和思乡联系起来。英文授课项目里的学术英语，不等于能用当地语言处理看病、租房、行政窗口和招聘。[欧洲六国研究](https://www.sciencedirect.com/science/article/pii/S0147176716301614)、[德国语言资本研究](https://onlinelibrary.wiley.com/doi/full/10.1002/psp.2725)
- 美国亚裔调查记录了“永远的外国人”“模范少数族裔”等刻板印象和具体歧视经历。遭遇差异很大，不能设置为每个海外角色必经，也不能把它解释为角色不够努力融入。[Pew 调查](https://www.pewresearch.org/race-and-ethnicity/2023/11/30/asian-americans-experiences-with-discrimination-in-their-daily-lives/)

### 2026 第一份工作

- 2026 届国内高校毕业生就业政策同时强调校园招聘、市场化岗位、国企事业单位招聘、基层项目、科研与教学助理等多种出口；春招是毕业前的重要补录窗口，但不是所有人都在同一时间拿到结果。[教育部春季促就业行动](https://hudong.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202603/t20260319_1431535.html)、[就业公共服务进校园](https://www.moe.gov.cn/jyb_xxgk/moe_1777/moe_1779/202604/t20260403_1432954.html)
- 本科直接就业通常更早积累在岗年限和通用项目证据，也更容易从实习、校招、桥接岗位进入；早期岗位层级和专业匹配可能较弱。
- 研究生就业可以进入更专业、研究或资格导向岗位，但也可能遇到方向过窄、实际项目不足、岗位不认研究题目、年龄和空窗成本。研究生路线是不同的机会结构，不是本科路线的数值升级版。
- 海外求职还要额外处理当地语言、工作资格、雇主手续和本地推荐；回国求职要处理学历材料、秋招节奏与“海归是否自动值钱”的落差。

## 现实难点与可用事件

| 环节 | 难点 | 可用场景 |
|---|---|---|
| 国内选课 | 必修冲突、先修课、热门课容量 | 选课系统开放三分钟，验证码比专业课先把人筛掉 |
| 社团与实践 | 时间、关系、履历和真实兴趣冲突 | 社团迎新承诺一学期，群公告先排到期末 |
| 休学／复学 | 手续、住房、家庭压力、复学窗口 | 学籍还在，宿舍床位和同届群已经不在 |
| 转专业／转学 | 名额、成绩、课程损失与材料 | 转成了，但培养方案多出一年；没转成，也留下能用的课 |
| 读研申请 | 材料、初试／复试、推荐、调剂、资助 | “拟录取”截图发完朋友圈，材料审核又要补一页 |
| 海外安顿 | 合租、账单、交通、预约、饮食 | 垃圾分类考试比期中更早到来 |
| 社会融入 | 同胞支持、当地关系、国际朋友圈 | 群里人人说“随时约”，日历共同空档在下学期 |
| 种族化处境 | 名字、口音、被当成单一群体、明显排斥 | 名字被改到第四版；玩家可纠正、求助、记录或换环境 |
| 本科就业 | 履历薄、专业不对口、实习转正 | 招聘先问“有经验吗”，岗位标题写“应届生” |
| 研究生就业 | 研究过窄、过度资格、缺行业证据 | 学历很好，岗位系统的下拉框不认识研究方向 |
| 海外就业 | 身份、当地语言、本地经验 | 招聘会先问工作资格，五分钟后才轮到专业 |
| 回国就业 | 认证、秋招节奏、薪资预期 | 认证还在路上，校招系统已经把“应届”变成灰色 |

## 黑色幽默边界

可以笑：

- 选课、报销、材料、群聊、招聘系统和相互矛盾的行政窗口。
- “保研、考研、留学、就业四手准备”最后发现一周仍只有七天。
- 研究题目写了三年，招聘网站把它自动归类为“其他”。
- 合租厨房的锅各有国籍，锅盖没有。

不能笑：

- 口音、名字、肤色、贫困、心理困扰或受到歧视的人。
- 把“中国学生只抱团”“本地人都排外”“美国／欧洲生活都一样”写成系统规则。
- 把忍耐骚扰或歧视设置为高收益选择。
- 用族裔、性别或国籍直接乘算录取和求职失败率。

## 状态映射

- 教育证据拆为课程、校园、实践和研究四类，避免一项“学历值”包办所有结果。
- `localTies` 与 `chineseCommunityTies` 是互补关系；两者可以同时增长。
- `hostLanguage` 区分授课能力和当地社会语言。
- `discriminationLoad` 只累计遭遇和压力，可由记录、盟友、支持服务、设边界或换环境缓解；不进入录取或求职成功公式。
- 第一份工作解析读取最高已完成学历、申请地区、四类证据、语言、关系、岗位匹配和工作资格。

## 不应编码的结论

- 不能从有限访谈推导国家或族群的固定性格。
- 不能把研究生收入、本科收入或留学回报写成确定数字。
- 不能把具体学校、专业、签证类别或 2026 临时政策永久投射到未来。
- 不能把“回国”或“留下”设为道德上更正确的结局。
- 不能复制网络自述中的可识别人物、学校、公司或极端遭遇。

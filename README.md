# 人生尚未加载 · 2026

一款中文移动端人生模拟游戏。

你在 2026 年出生。出生地和家庭会影响最初的生活，之后读什么书、做什么工作、跟谁生活、要不要孩子、如何花钱，都由这一生里真正发生过的事继续往下推。

[在线游玩](https://jayden2young-netizen.github.io/life-unloaded-2026/)

## 怎么玩

1. 随机生成出生地、家庭成员和家庭情况。
2. 分配六项初始属性，再选一张伴随人生的卡牌。
3. 轻触时间线，每次推进一件事。
4. 遇到岔路时，从当下确实做得到的选项里选择。
5. 这一生结束后，查看人生画像、三次重要转折和专属结局。

一局会从出生推进到死亡，当前候选版的普通选择目标为 22—28 次，并为童年和晚年分别保留选择空间。14 岁与成年后的两次人生排序，各自最多会为已经成熟的具体目标增加一次可拒绝的机会；强制经历仍可能让实际选择数更高。游戏会自动存档，不需要注册账号。

## 你可能经历什么

有人一路读到大学，也有人读职校、考证、辍学后再回到课堂。工作可以是企业、公职、平台劳动、远程接单或自己开店；你也可以暂时不工作，把时间用来照护家人、养病或者单纯生活。

感情可能走向恋爱、同居、婚姻、分开和再婚。你可以生育、收养、成为继父母，也可以主动不要孩子。房子、债务、疾病、成瘾、养老和遗嘱不会只出现一次，它们可能过几年又回来，换一种方式影响你。

大多数人生不会整齐地成功或失败。普通日子、偶然好运和麻烦事会混在一起。极少数路线可以走到巨额财富，也可能留下还不完的债。

## 选择会留下什么

选择不会保证一个好结果。它可能带来收入，也可能占掉时间；保住一段关系，也可能让另一件事被耽误。家庭、能力、现金、健康和已经认识的人会决定你当时能做什么。

过去的选择会在几年后产生后果。结局只会引用这一生真实发生过的转折，不会因为碰巧见过某个主题就给出不相干的标题。

## 当前版本

当前公开版本仍是 v0.6.13；本分支正在验证 v0.7.0 候选（Schema 14／Content Revision 36），项目仍在早期开发中。候选五轮真人完整阅读通过前，不进入发布阶段。

v0.6.13 把关键选择拆成六个年龄阶段的独立预算，重做首职失败后的第二步、所有稳定工作的成长机会和 55—65 岁工作转段；年度事实、选择和生活纹理会一次排定并随存档恢复。时间线、状态摘要和结局也改为优先承认这一生真正发生过的首职、工作成长、家庭、住房、债务、健康、人物死亡和晚年转段。

v0.6.10 新增独立的社会交往轨道。同学、同事、室友、邻居、兴趣活动和线上关系会进入普通日常，也可能留下最多两位跨年龄出现的具体朋友。认识面、真心朋友、主动独处和想联系却无人可找不是同一个分数；拒绝聚餐、活动或合住不会自动增加孤独。

关键社交结果会在少量明确场景中稳定地产生不同回响，刷新或恢复存档不会重抽。朋友可以提供一次工作线索、合法合住或暂住入口、有限危机支持，也可以在双方愿意时进入约会；这些入口仍须经过就业、住房、债务、健康、照护和伴侣系统原有的硬条件。

住校、单位宿舍、朋友短住和短期照护只改变当时住在哪里，不会让名下房产或按揭凭空消失。选项中的多条变化仍整组结算；任何硬条件失败时，不会留下半次关系创建、搬迁、扣款或工作入口。212 个卡牌互动均由具体事件显式创作。

## 存档

存档保存在当前浏览器中。设置页可以导出存档，也可以使用“清除全部数据”删除当前人生和所有跨局记录。

版本更新后，尚未结束的一生可能需要重新开始；已经留下的人生记录、图鉴、设置和统计会继续保留。清理浏览器数据或更换设备前，建议先导出存档。

## 项目验证

项目根目录的 `smoke.js` 是统一入口：

```bash
node smoke.js          # 日常：合同检查 + 核心浏览器回归
node smoke.js --fast   # 秒级：全部脚本语法检查
node smoke.js --full   # 发布前：全部当前版本回归
```

更多定向检查可用 `node smoke.js --list` 查看。正常开发优先跑受影响路径，只有发布或共享基础设施变更才跑 `--full`。

## 本地试玩

下载项目后，在项目目录启动一个本地服务器。

macOS 可以直接双击项目根目录的 `start-local-play.command`。脚本会启动 Python 本地服务器并打开默认浏览器；试玩期间保留弹出的终端窗口，结束时在窗口中按 `Control+C`。如果 macOS 第一次阻止运行，可右键脚本选择“打开”。

也可以在 macOS 或 Linux 终端手动启动：

```bash
python3 -m http.server 8765
```

Windows：

```shell
py -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。游戏通过浏览器读取本地数据，直接双击 `index.html` 无法正常启动。

发现事件与年龄、工作、伴侣或子女状态对不上时，可以在 [GitHub Issues](https://github.com/jayden2young-netizen/life-unloaded-2026/issues) 留下当时的年龄、状态和事件文字。能附上种子编号会更容易复现。
